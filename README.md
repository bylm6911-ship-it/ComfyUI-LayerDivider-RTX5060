# ComfyUI-LayerDivider-RTX5060
ComfyUI LayerDivider compatibility package for RTX 5060, based on jtydhr88/ComfyUI-LayerDivider.
## Requirements

- Windows 10/11
- [Miniconda](https://docs.conda.io/en/latest/miniconda.html)
- NVIDIA RTX 5060 GPU
- [ComfyUI](https://github.com/comfyanonymous/ComfyUI)

## Installation

1. Install [Miniconda](https://docs.conda.io/en/latest/miniconda.html)
2. Clone or download this repo into your `ComfyUI/custom_nodes/` folder
3. Run `FIRST_TIME_SETUP.bat` **once** to install the environment (no need to run again)

## Usage

Every time you want to use ComfyUI, run `RUN.bat` to start.
